
# Sales Data Analysis Using SQL

## Project Overview
Analyzed sample sales data using SQL to understand
product performance, revenue, and regional sales trends.

## Dataset
The dataset contains 10 sales transactions with:
- Sale date
- Product and category
- Quantity and price
- Region

## SQL Concepts Used
- SELECT and aggregate functions
- GROUP BY and ORDER BY
- HAVING
- Monthly sales analysis
- Revenue calculations

## Key Findings
- Total revenue: 304,900
- Total transactions: 10
- Total units sold: 40
- Average sale value: 30,490
- Highest-revenue product: Laptop
- Highest-revenue region: South
- Highest-revenue month: March

## Tools
- MySQL
- DB Fiddle

## Files
- schema.sql: Creates the table and inserts sample data.
- analysis.sql: Contains the sales analysis queries.
- README.md: Documents the project.
